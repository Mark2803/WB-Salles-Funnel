# WB Воронка — инструкция для работы с кодом

Инструмент магазина «Чайный Мастер» на Wildberries: сбор данных по WB API, сводка, юнит-экономика, стратегии и симулятор. Владелец — Марк. Общение и комментарии в коде — на русском, объяснять простыми словами: Марк не программист.

## Главное

- **Без сторонних библиотек.** Node.js ≥ 22.5: `node:http`, `node:sqlite`, `fetch`, `node:test`. Не добавлять npm-зависимости без явной просьбы — на сервере их некому обновлять.
- **Только чтение из WB.** Инструмент ничего не меняет в кабинете WB (цены, ставки, ответы на отзывы). Токен — персональный, «Только чтение».
- **Секреты только в `.env`** (в git не коммитить): `WB_API_TOKEN`, `ADMIN_PASSWORD_HASH`, `SESSION_SECRET`. Токен не выводить в логи и на экран.
- **Методы WB API** взяты из официальной спецификации dev.wildberries.ru (снимок 09.11.2026). WB часто меняет методы — при ошибке 404/400 сначала сверить с актуальной документацией. Лимиты: аналитика и реклама — 3 запроса/мин, финотчёт — 1/мин (см. `src/wb/client.mjs`).
- **Органических показов в API нет**: воронка начинается с переходов в карточку. Показы/CTR — только по рекламе. Поиск и позиции — только с подпиской «Джем».
- **Эффекты стратегий — допущения**, они помечены `kind: 'assumption'` и видны пользователю. Не выдавать прогноз за факт.

## Команды

- `npm start` — запуск; `npm run dev` — тестовые данные (`WB_MOCK=1`).
- `npm test` — автотесты (сеть не нужна). Запускать перед каждым коммитом.
- `npm run collect` / `npm run collect -- full` — разовый сбор.
- `npm run check` — проверка токена (категории, срок, только чтение).
- `npm run hash-password` — пароль для входа.
