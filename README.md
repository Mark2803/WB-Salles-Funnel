# WB Воронка — инструмент магазина «Чайный Мастер» на Wildberries

Следит за воронкой продаж по выбранным артикулам WB, считает юнит-экономику и помогает выбирать стратегии продвижения: симулятор показывает, как изменятся заказы и прибыль, а после запуска — «план против факта».

Адрес после установки: **https://tea-master-team.ru/wb-funnel/** (вход по паролю).

## Что умеет

| Вкладка | Что там |
| --- | --- |
| **Сводка** | Итоги за 7 дней против прошлых 7, тревоги («кончается остаток», «негативный отзыв без ответа», «ДРР выше цели», «продажа в минус»…), таблица артикулов со светофором |
| **Товар** (клик по строке) | Воронка, графики по дням с отметками из журнала, реклама, цена и остатки, юнит-экономика по фактам финотчёта, поисковые запросы, отзывы |
| **Стратегии** | 6 стратегий с шагами, условиями входа и стоп-правилами; симулятор на 30 дней; сравнение всех стратегий; планы и «план против факта» |
| **Журнал** | Что и когда меняли (цена, фото, реклама, поставки) — видно на графиках |
| **Настройки** | Себестоимость, параметры юнит-экономики, пороги тревог, история сбора данных |

Кнопка **«Сводка для Claude»** копирует отчёт в Markdown — его можно вставить в чат и обсуждать стратегию на живых цифрах.

## Откуда данные (WB API)

| Данные | Метод WB | Как часто |
| --- | --- | --- |
| Переходы, корзины, заказы, выкупы по дням | `POST /api/analytics/v3/sales-funnel/products/history` | каждые 3 ч (последние 7 дней) |
| Остатки, рейтинг, срок доставки | `POST /api/analytics/v3/sales-funnel/products` | каждые 3 ч |
| Цены и скидки | `POST /api/v2/list/goods/filter` | каждые 3 ч |
| Реклама: показы, клики, CTR, расход, заказы | `GET /api/advert/v3/adverts`, `GET /adv/v3/fullstats` | каждые 3 ч |
| Отзывы | `GET /api/v1/feedbacks` | раз в сутки |
| Фактические комиссия, логистика, хранение | `POST /api/finance/v1/sales-reports/detailed` | раз в сутки |
| Позиции в поиске, видимость, запросы | `POST /api/v2/search-report/product/search-texts` | раз в сутки, **только с подпиской «Джем»** |

Важно: **органических показов и общего CTR в API WB нет** — воронка начинается с переходов в карточку. Показы и CTR есть только по рекламе.

## Как устроено

Node.js 22 без сторонних библиотек: встроенный HTTP-сервер, встроенная база SQLite (`data/wb.sqlite`), встроенный `fetch`. Устанавливать пакеты не нужно.

```
src/server.mjs      сервер и раздача страницы
src/api.mjs         JSON API для страницы
src/sync.mjs        запуск сбора и планировщик
src/wb/client.mjs   запросы к WB API с учётом лимитов
src/wb/collect.mjs  сбор и разбор ответов WB
src/wb/mock.mjs     тестовые данные (WB_MOCK=1)
src/metrics.mjs     воронка, юнит-экономика, тревоги
src/strategies.mjs  стратегии и симулятор
src/summary.mjs     «Сводка для Claude»
public/             страница (HTML, JS, CSS)
tests/              автотесты (npm test)
deploy/             служба systemd и настройка nginx
```

## Установка на сервер (один раз)

Выполнять под `root` в свежем SSH-терминале. Код и данные — от имени `ivanc1539`.

1. **Токен WB.** В кабинете WB → «Интеграции по API» → «Создать токен» → **Персональный**, уровень **«Только чтение»**, категории: **Аналитика, Цены и скидки, Продвижение, Вопросы и отзывы, Финансы**. Скопируйте токен — в чат его не отправлять.

2. **Код:**
   ```
   U="runuser -u ivanc1539 --"
   cd /home/ivanc1539
   $U git clone https://github.com/Mark2803/WB-Salles-Funnel.git wb-salles-funnel
   cd wb-salles-funnel
   $U cp .env.example .env
   $U npm run hash-password
   ```
   Последняя команда попросит придумать пароль для входа и выведет две строки `ADMIN_PASSWORD_HASH=…` и `SESSION_SECRET=…`.

3. **Настройки.** Откройте `.env` (`nano .env`) и заполните: `WB_API_TOKEN=` (токен из шага 1), две строки из шага 2. Остальное оставить как есть.

4. **Проверка токена и первый сбор:**
   ```
   $U npm run check
   $U npm test
   $U npm run collect -- full
   ```
   `check` покажет, какие категории есть у токена. `collect` занимает 10–15 минут из-за лимитов WB (3 запроса в минуту к аналитике и рекламе). Шаг «Поиск и позиции» без подписки «Джем» закончится ошибкой — это нормально.

5. **Служба:**
   ```
   cp deploy/wb-funnel.service /etc/systemd/system/
   systemctl daemon-reload && systemctl enable --now wb-funnel
   sleep 3 && systemctl is-active wb-funnel && curl -s http://127.0.0.1:3200/api/me
   ```
   Ответ `{"authenticated":false,...}` — сервер работает.

6. **Адрес в nginx.** Скопируйте содержимое `deploy/nginx-wb-funnel.conf` в блок https-сайта (на HestiaCP — файл `/home/ivanc1539/conf/web/tea-master-team.ru/nginx.ssl.conf_wb-funnel`), затем `nginx -t && systemctl reload nginx`. Откройте https://tea-master-team.ru/wb-funnel/.

## Обновление

```
cd /home/ivanc1539/wb-salles-funnel
runuser -u ivanc1539 -- git pull
runuser -u ivanc1539 -- npm test
systemctl restart wb-funnel
```

Резервная копия данных — один файл: `cp data/wb.sqlite /home/ivanc1539/backup-wb-$(date +%F).sqlite`.

## Проверка без токена

`WB_MOCK=1 npm start` — тестовые данные (выдуманные), удобно для проверки интерфейса.

## Журналы и ошибки

- `journalctl -u wb-funnel -n 100` — журнал сервера.
- История сбора с ошибками по шагам — вкладка «Настройки».
- 401 от WB — токен истёк (живёт 180 дней) или скопирован неверно; 403 — у токена нет нужной категории или нужна подписка «Джем».
